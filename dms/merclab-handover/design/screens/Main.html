DMS design system

Workshop Glass: frosted surfaces, silver neutrals and XENTRY blue. Quiet enough to trust with money, sharp enough to read in a bright workshop.

Version1.0 · 19/11/2026For: developer team · Approver: the Chairman
Phone first

New estimate, Record payment, Send on WhatsApp and Move stage are one thumb-tap away.

One primary action

Each screen has one blue button. Everything else is quiet glass.

Numbers that matter stand out

Owed, paid, balance and stage use the display size and the status colours.

Same markup, new skin

Existing class names are kept, so app.js templates change step by step.

07

Accessibility and device rules

Built for dirty hands on a tablet and the owner's thumb on a phone.

44px tap targets

Buttons, chips, tabs, list rows, nav items and stage steps are at least 44px tall. Phone primary actions are 52px.

16px inputs

Every input, select and textarea uses 16px text so iPhone never zooms in on focus.

WCAG AA contrast

All text tokens pass 4.5:1 on their surfaces, including muted labels and status text on soft fills.

Keyboard first on PC

Visible 2px blue focus ring with 2px offset. Ctrl K opens search. Real buttons and links everywhere.

Safe areas

Top bar adds env(safe-area-inset-top); bottom bar and action bar add env(safe-area-inset-bottom).

Bright workshop

Light ground, ink text, no thin grey-on-grey. Status uses word + colour, never colour alone.
