Merc Lab DMS redesign

Notes for developers

The design is built from one stylesheet, merclab.css, which every artboard on this canvas uses. Drop it in beside style.css, re-skin screen by screen, then delete the old file.

Shell

// app.js: sidebar group (only the active group is open)
const navGroup = (g, items, route) => {
  const open = items.some(i => route.startsWith(i.href));
  return `<details class="nav-g" ${open ? "open" : ""}>
    <summary>${g}${!open && g.alert ? `<span class="dot-n">${g.alert}</span>` : ""}${icon("cd","ic s chev")}</summary>
    ${items.map(i => `<a href="${i.href}" class="${route.startsWith(i.href) ? "on" : ""}">${icon(i.icon)}<span>${i.label}</span></a>`).join("")}
  </details>`;
};

06

Suggested order (each step ships on its own)

  1. Tokens only. Swap the :root block and fonts. Nothing else changes; the app already looks calmer. Ship.
  2. Shell. Logo, light sidebar with <details> groups, top bar, phone .bar with Create sheet. Fixes pain points 3 and 7.
  3. Status system. One statusPill() helper used by pills, stage tags and tiles. Fixes 8.
  4. Tables → lists. Jobs, Customers, Money first, then every list page. Fixes 2.
  5. Job page. Stage bar + Move button, right rail with money, .actbar on phone. Fixes 5 and 6.
  6. Dashboard. Desktop regroup, phone order: tiles → Needs action → board tabs → bookings → collapsed sections. Fixes 1.
  7. Estimate form. Totals in the rail (desktop) / .actbar (phone), Add-a-line sheet. Fixes 4.
  8. Everything else with the four patterns (list, detail, form, report).
07

What does not change

  • Hash routes and the server API: unchanged.
  • The A4 estimate, invoice and official receipt: unchanged. Only the web wrapper on /d/:token takes the new tokens (approve box = .card + .btn.lg + .notice.ok).
  • condition.js geometry and tap logic: unchanged. Only the colours come from the --car-* tokens, and the kind picker uses .kinds. On phone, show one view at a time with a .seg to switch.
  • Every screen, button and field that exists today still exists. Some moved: phone job actions sit in More; Cars sits in the phone More menu.
