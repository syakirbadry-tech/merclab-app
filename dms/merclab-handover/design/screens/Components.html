Shell rules

Sidebar: groups are <details>. Only the group holding the current page is open; closed groups show a small alert ("2 due", "4 low") so nothing is hidden silently. Longest open state is 5 items, so the whole menu fits in 760px with no inner scroll.

Active item: light grey fill, ink text and a 3px ink marker on the left. Selected chips use the same light grey.

Phone: Home, Jobs, Create, Money, More. Create opens the bottom sheet (New estimate, Record payment, Payment slip, New booking). "Cars" moves into More and into search, which finds any plate.

On a job page the bottom bar is replaced by the action bar: More, WhatsApp, and one primary action that follows the stage (Move to …, Make invoice, Record payment).
